# UV Sensor System in Embedded Rust

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Language: Rust](https://img.shields.io/badge/Rust-Embedded-orange.svg)](https://www.rust-lang.org/)

## 🇪🇸 Descripción del Proyecto
La idea es implementar un sistema de medición de radiación ultravioleta usando un sensor **ZTS-300AL-RA-N01** sobre protocolo industrial **RS485**, y recibir los datos en dos tipos de sistemas embebidos: una **ESP32-LoRa** y una **STM32 Nucleo (Nucleo-L073RZ)**. 

De manera inicial, la implementación se realiza usando **Rust** como lenguaje de programación, con la intención de impulsar y apoyar el desarrollo de sistemas embebidos seguros y eficientes usando Rust.

---

## 🇬🇧 Project Description
The idea is to implement an ultraviolet radiation measurement system using a **ZTS-300AL-RA-N01** sensor over the **RS485** industrial protocol, and receive the data on two types of embedded devices: an **ESP32-LoRa** and an **STM32 Nucleo (Nucleo-L073RZ)**.

Initially, the implementation is done using **Rust** as the programming language, with the intention of advancing the development of embedded systems using Rust.

---

## 🛠️ Hardware Requirements
* **UV Sensor:** ZTS-300AL-RA-N01 (RS485 interface)
* **Target 1:** ESP32-LoRa
* **Target 2:** STM32 Nucleo (Nucleo-L073RZ)
