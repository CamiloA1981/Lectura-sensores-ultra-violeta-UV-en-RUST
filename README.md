# Lectura-sensores-ultra-violeta-UV-en-RUST
La idea es implementar un sistema de medición de radiación ultravioleta usando un sensor ZTS-300AL-RA-N01 sobre protocolo industrial RS845 y recibir los datos en dos tipos de embebidos una esp32-LoRa y una STM32nucleo nucleo-L073RZ.
De manera inicial la implementación se haría usando RUST como lenguaje de programación, la intención es ayudar al desarrollo de sistemas embebidos usando RUST.

The idea is to implement an ultraviolet radiation measurement system using a ZTS-300AL-RA-N01 sensor over the RS485 industrial protocol, and receive the data on two types of embedded devices: an ESP32-LoRa and an STM32 Nucleo (Nucleo-L073RZ).

Initially, the implementation will be done using Rust as the programming language, with the intention of advancing the development of embedded systems using Rust.
